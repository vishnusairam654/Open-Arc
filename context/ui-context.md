# UI Context

## Theme

Dark only. No light mode. The visual language is a premium, cinematic Material 3 (M3) dark technical workspace — near-black backgrounds, physical elevation surfaces, micro-interactions, and vivid accent tokens.

All colors are defined as CSS custom properties in `globals.css` and mapped to Tailwind tokens via `@theme inline`. Components must use these tokens — no hardcoded hex values or raw Tailwind color classes like `zinc-*`.

| Material 3 Role        | CSS Variable           | Hex / Value               | Design Notes                                     |
| ---------------------- | ---------------------- | ------------------------- | ------------------------------------------------ |
| Surface (Base)         | `--bg-base`            | `#080809`                 | Full-viewport canvas backdrop                    |
| Surface Container Low  | `--bg-surface-low`     | `#111114`                 | Primary background for structural panels         |
| Surface Container      | `--bg-surface`         | `#161619`                 | Default surface for cards and toolbars           |
| Surface Container High | `--bg-surface-high`    | `#1d1d22`                 | Hovered states or detached popovers              |
| Surface Bright         | `--bg-surface-bright`  | `#24242a`                 | Dialogs, modals, and active elements             |
| Outline (Default)      | `--border-default`     | `#2a2a30`                 | M3 low-contrast structural dividers              |
| Outline Variant        | `--border-subtle`      | `#3a3a42`                 | Interactive borders and focus boundaries         |
| On Surface (Primary)   | `--text-primary`       | `#f0f0f4`                 | High-emphasis readable text                      |
| On Surface Variant     | `--text-secondary`     | `#c0c0cc`                 | Medium-emphasis labels and body text             |
| Muted / Disabled       | `--text-muted`         | `#808090`                 | Low-emphasis utility text and hints              |
| Brand Primary          | `--accent-primary`     | `#00c8d4` (Cyan)          | Interactive states, focus rings, primary actions |
| Brand Primary Dim      | `--accent-primary-dim` | `rgba(0, 200, 212, 0.12)` | Component container fills (e.g., chips)          |
| AI Secondary Accent    | `--accent-ai`          | `#6457f9` (Indigo-purple) | AI generation boundaries and sparkles            |
| On AI Accent           | `--accent-ai-text`     | `#8b82ff`                 | Text/icons overlaying AI surfaces                |
| Error                  | `--state-error`        | `#ff4d4f`                 | Destructive actions and broken states            |
| Success                | `--state-success`      | `#34d399`                 | Completed tasks and online indicators            |
| Warning                | `--state-warning`      | `#fbbf24`                 | Token validation or mutation alerts              |

Tailwind utility names map to these variables. Use `bg-base`, `bg-surface-low`, `text-copy-primary`, `border-surface-border`, `text-brand`, `bg-accent-dim`, etc.

## Motion & Animations

The system uses a highly responsive, cinematic motion model built using animation libraries (Framer Motion / GSAP) to simulate physics-based material movement. No jarring cuts.

### Material 3 Easing & Durations

- **Emphasized Easing (Standard):** `cubic-bezier(0.2, 0, 0, 1)` — Used for primary panel entries and large canvas transformations.
- **Decelerate Easing (Exit):** `cubic-bezier(0, 0, 0.2, 1)` — Used for elements leaving the viewport.
- **Accelerate Easing (Enter):** `cubic-bezier(0.3, 0, 1, 1)` — Used for minor toggle transitions.

### Motion Tokens

| Pattern / Target          | Animation Type          | Duration / Properties    | Behavior Description                                                              |
| ------------------------- | ----------------------- | ------------------------ | --------------------------------------------------------------------------------- |
| Sidebar Flyouts / Drawers | Spring / Layout Shift   | `duration-500` (500ms)   | Emphasized slide + fade with subtle overshoot backdrop blur.                      |
| Node Hover & Selection    | Scale & Glow Transition | `duration-200` (200ms)   | Smoothly scales node up `1.02x` and expands an outer Material state outline glow. |
| Canvas Node Creation      | Scale In Stagger        | `duration-400` (400ms)   | Nodes generated by AI scale from `0.8` to `1` using an elastic spring effect.     |
| Real-time Cursors         | Interpolated Path       | Latency-free GSAP ticker | Cursors glide smoothly between presence coordinates to avoid jitter.              |
| Dialog Overlays           | Scale + Backdrop Blur   | `duration-300` (300ms)   | Dialog pops forward from `0.95` scale while background blurs over 300ms.          |

## Typography

| --------- | ---------- | ------------------- |
| UI text   | Geist Sans | `--font-geist-sans` |
| Code/mono | Geist Mono | `--font-geist-mono` |

## Border Radius

Strictly follows the Material 3 shape classification scale to indicate structural boundaries.

| M3 Shape Category | Context                           | Class          |
| ----------------- | --------------------------------- | -------------- |
| Small             | Tooltips, Canvas Handles          | `rounded-md`   |
| Medium            | Inline UI, Context Menus          | `rounded-xl`   |
| Large             | Canvas Nodes, Control Bars        | `rounded-2xl`  |
| Extra Large       | Floating Sidebars, Sheet Overlays | `rounded-3xl`  |
| Full              | Active Pills, User Avatars, FABs  | `rounded-full` |

## Canvas

### Node Style & Color Palette

Nodes are rendered as Material Surfaces. Instead of flat borders, they use physical layering principles: a thin dark outline (`--border-default`) accompanied by a subtle Material 3 `elevation-1` or `elevation-2` shadow backdrop.

There are 8 defined color pairs for node differentiation, mapped in `types/canvas.ts` as `NODE_COLORS`.

| Node Container Fill | Typography / Icon Color | Material Association   |
| ------------------- | ----------------------- | ---------------------- |
| `#1F1F1F`           | `#EDEDED`               | Neutral Dark (Default) |
| `#10233D`           | `#52A8FF`               | Blue (Services)        |
| `#2E1938`           | `#BF7AF0`               | Purple (Gateways)      |
| `#331B00`           | `#FF990A`               | Orange (Queues)        |
| `#3C1618`           | `#FF6166`               | Red (Alerts/Compute)   |
| `#3A1726`           | `#F75F8F`               | Pink (Caching)         |
| `#0F2E18`           | `#62C073`               | Green (Storage)        |
| `#062822`           | `#0AC7B4`               | Teal (External APIs)   |

### Edge Style

Smooth-step path utilizing an arrow marker head. Default edge color: `#3a3a42` (`--border-subtle`). When an edge is selected, it transitions smoothly via Framer Motion to `--accent-primary` (Cyan) and increases its stroke thickness from `1.5px` to `2.5px` with a marching-ants dash array animation indicating active data flow.

### Node Shapes

6 supported shapes, defined in `types/canvas.ts` as `NODE_SHAPES`. Complex shapes are rendered as highly precise inline SVGs to maintain clean anti-aliasing during canvas zooming.

- `rectangle` — default M3 Large container node
- `diamond` — decision / gateway
- `circle` — event / endpoint
- `pill` — service / process (fully rounded sides)
- `cylinder` — database / storage
- `hexagon` — external system / boundary

### Connection Handles

Small white circular handles matching `rounded-full`. Hidden by default. On node hover, handles dynamically animate into view using a spring scale transition from `0` to `1`. Placed symmetrically at all four cardinal sides of a node.

### Canvas Background

React Flow `<Background>` component configured in `dots` mode. The canvas surface floats on the base background color (`--bg-base`).

## Component Library

Material-inspired Tailwind primitives built on top of accessible components (like Radix primitives or an unstyled base layer) rather than raw generic systems. Focuses heavily on the Material 3 interaction states: **Hover** (surface tint overlay), **Focus** (high-contrast outer stroke), and **Pressed/Active** (internal scaling or dimming).

## Layout Patterns

- **Editor Workspace:** Full-viewport layout. The background is a clean canvas surface, layered over by absolute-positioned floating layout components that use Material elevation rules.
- **Sidebars & Slide-overs:** Floating overlay sheets positioned with an offset from the viewport edge. Features a dark semi-transparent container background, high blur backdrops (`backdrop-blur-md`), and `rounded-3xl` corners to resemble an elegant, floating canvas UI.
- **FABs (Floating Action Buttons):** Main triggers (e.g., "Generate Spec" or "AI Chat") are styled as high-elevation Material FABs using `rounded-2xl` shapes, a vivid `--accent-primary` or `--accent-ai` background, and explicit layout scale animations on state updates.
- **Modals & Dialogs:** Centered overlay containers utilizing `rounded-3xl` configurations, `bg-surface-bright` fills, and an intensive backdrop blur layer to keep focus isolated from the live canvas layout underneath.

## Icons

Lucide React. Stroke-based icons only — no filled variants to maintain a technical look. Icon sizes follow the strict Material scale: `h-4 w-4` for compact inline badges, `h-5 w-5` for structural buttons and sheet triggers, and `h-8 w-8` for prominent feature headers in zero-states.
